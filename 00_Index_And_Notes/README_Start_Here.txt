This repository contains all of the raw data for all applicable blueprints. This is not meant to be a publicly shared collection. This is for my own personal use with AI to help me navigate this system. This repository is structured to separate the system into sub-folders which will contain .txt files which contain raw data for individual blueprints and/or widgets. I will add a separate Index file which states all of the functions and/or events which are covered within the main file within that folder. The "main file" will have the suffix _RawGraphs . The Index file will have the name of the correlating blueprint with the suffix _Index.
